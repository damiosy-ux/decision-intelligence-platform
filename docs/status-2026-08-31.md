## Public Boundary

The repository demonstrates architecture, schemas, validation, normalization, offline evaluation, diagnostics, tests, and CI. It does not publish private datasets, credentials, provider endpoints, extraction mechanics, production automation, calibrated models, proprietary thresholds, or operational scoring combinations.

Scores in the reference implementation represent satisfied rule groups. They are not probabilities, guarantees, or calibrated confidence estimates.
