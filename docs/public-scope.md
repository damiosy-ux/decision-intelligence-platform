# Public Scope

This repository is a portfolio-safe reference implementation.

It demonstrates the structure of a decision-intelligence workflow without publishing private source integrations, proprietary datasets, operational heuristics, or production strategy.

## Included

- Synthetic sample records
- Generic rule configuration
- Small explainable evaluation engine
- Architecture notes
- Testable Python implementation
- Public-data prototype script

## Not Included

- Private data sources
- Production credentials
- Provider-specific operational playbooks
- Proprietary entity-resolution logic
- Full scoring methodology
- Full draw-intelligence methodology
- Proprietary thresholds and comparison rules
- Source-specific harvesting and synchronization tactics
- Historical outcome datasets
- Production monitoring or automation rules
- Private research notes and post-event learning records

## Design Intent

The public version is designed to show engineering capability:

- clean data models
- repeatable evaluation
- externalized configuration
- transparent diagnostics
- test coverage
- documentation

The deeper research workflow can remain private while this repository demonstrates the reusable architecture.

## Draw-Intelligence Boundary

The draw-oriented research direction is documented publicly only as an architectural case study. Public materials may describe high-level stages such as evidence harvesting, normalization, slice comparison, offline evaluation, diagnostics, and learning loops.

The public repository must not include the private engine's source-specific parsing details, exact thresholds, scoring combinations, validated fixture history, provider tactics, or operational automation logic.
